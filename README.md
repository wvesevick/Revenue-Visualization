# Revenue-Visualization "Wedge Effect"

This project displays the projected end of fiscal year revenue for our company by calculating MRR and churn for each month. Please see the following 2 examples

# example 1: 
If in November we gain a monthly contract for $100 and we lose a monthly contract for $50, Revenue Projection will be calculated like this:
    
      Nov: $50
      Dec: $100
      Jan: $150
      ...
      Oct: $600

# example 2:
If our MRR is $15,157 in November, $17,565 in December, $22,492 in January
and churn is $16,279 in November, $9,692 in December, $15,684 in January
